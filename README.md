# NoAiAndPythonProject


## What does it do?

This repo was made to learn the programming language Python. Each one of us
has a branch with projects, and each of us picked an idea we wanted to build.

## But why?

We did this as a challenge to ourselves. We are usually very dependent on AI
when it comes to coding, so we wanted to change that for at least one language.
Since neither of us knew much Python, we decided to learn this one.

## How to run the projects

To try the small programs we made, you first need Python installed on your
device. Make sure to tick "Add Python to PATH" during installation.

Then clone this repo:

`git clone https://github.com/bergaminio/NoAiAndPythonProject.git`


Open the folder in your IDE and hit run, or start a file directly: `python [the file you want to start]`
